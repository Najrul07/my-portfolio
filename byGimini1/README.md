# Najrul Hoque — Personal Portfolio Website

A minimal, professional, monochrome developer portfolio designed for a BCA student seeking internships and junior web development opportunities.

## Tech Stack
- **HTML5**: Semantic tags, accessible layout design, SEO optimization.
- **CSS3**: Custom variables, Flexbox, Grid layouts, keyframe transitions, and responsive queries.
- **Vanilla JavaScript**: DOM manipulation, Theme switcher (LocalStorage), Mobile navigation state, Scroll animations (Intersection Observer), Form validation.

## Features
- **Monochrome Theme System**: Dark mode standard (`#0B0B0B`) with built-in Light mode toggle (`#F6F6F3`) persisted via `localStorage`.
- **Responsive Layout**: Designed to render smoothly from 320px mobile screens to desktop displays without layout shift or horizontal scrolling.
- **Mobile Navigation**: Accessible hamburger drawer menu with keyboard navigation escape handling.
- **Dynamic Content**: Auto-updating copyright date and dynamic scroll observer.
- **Honest Skill Representation**: Accurate presentation of current fundamentals and ongoing learning paths without exaggerated framework experience.
